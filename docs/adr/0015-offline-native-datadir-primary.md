# ADR-0015：离线直读 Nexus 原生数据目录为首选全量迁移路径

## 状态
已接受

## 背景
ADR-0007 把「在线 REST」与「JianArtifact 自有完整离线迁移包」并列为两个入口，且实践中在线是默认叙述。但真实迁移场景的存量常达数百 GB：逐对象走 Nexus REST/HTTP 拉取既慢又易受连接抖动影响（NFR-14 软目标即 100 GiB 在线约 4 小时），而要求用户先用工具把数百 GB「打包」成自有格式再导入，等于把同样的数据多拷一遍。用户明确要求：默认从磁盘上的 Nexus 原生数据直接迁移，不逐个 HTTP 拉、不额外打包。

关键技术事实厘清了取舍：
- Nexus 文件型 blob store 中每个 `.bytes` 都伴随 `.properties`，其中带有归属仓库、路径/坐标线索、sha1、大小、内容类型等——**数百 GB 的 blob 大头可从磁盘直读并归属，无需读 Nexus 的配置库**。
- 真正只存在于 Nexus 配置库中的是**少量仓库配置**：proxy 上游地址、group 成员关系、仓库级策略。
- Nexus 3.70.x 的内嵌配置库是 H2（或旧实例的 OrientDB），均为 JVM 生态私有二进制格式；本项目纯 Rust + 零系统级 C 依赖 + 单二进制交付，**没有可用的纯 Rust H2/OrientDB 读取方案**，直读磁盘配置库不可行。

## 决策
- **首选路径改为「离线直读 Nexus 原生数据目录」**：blob 大头从磁盘上的 Nexus 文件型 blob store 直接读取与归属；在线 REST 全量迁移降为**备选**（数据不在本机但 Nexus 可达时用）。
- **配置来源双支持**（体量极小，与 blob 解耦）：
  - Nexus 迁移时仍可达 → 经 REST **一次性拉取**仓库配置（proxy 上游、group 成员）；
  - Nexus 已下线不可达 → 由管理员在迁移向导**手动补**这些配置（扩展 ADR-0007/FR-039 已有的「管理员补 proxy 凭据引用」到上游地址与 group 成员）。
- **不采用直读内嵌配置库**（H2/OrientDB）：纯 Rust 不可行，明确排除，不为它引入 JVM 或重写私有格式解析器。
- **自有离线迁移包格式（ADR-0008）保留**为可选的可移植、带整体校验的归档形态（异地交付/审计场景），**不再是全量迁移的唯一离线入口**。
- **裸 blob store 降级不变**：仅有 blob、既无 REST 也无手动配置时，hosted 与已缓存内容可从磁盘尽力恢复，proxy 上游与 group 成员缺失的仓库标「配置待补充」，任务总状态不得全量成功（沿用 ADR-0007）。
- ADR-0007 的支持矩阵（仅 3.70.x）、全量成功完成定义、在线一致性（停写窗口 + 最终增量扫描）、双校验与幂等判据**继续有效**；本 ADR 只调整「入口构成与默认路径」，并新增原生数据目录直读源与配置双来源。原生数据目录的一致性由「迁移前停 Nexus 或取文件系统快照后再拷/挂载」保证，写入运维文档。

## 理由
- 数百 GB 场景下，磁盘直读 blob 比逐对象 HTTP 快一个量级且不受连接抖动影响；配置体量极小，单独走 REST 或手动补都廉价。
- blob 归属信息就在 `.properties` 里，读配置库对大头毫无必要——把「难且不可行的部分（读私有库）」从关键路径上移除，只留「小且有替代的部分（配置）」。
- 保留自有包格式满足确需可移植归档的少数场景，同时不强制大多数用户走多余的打包步骤。
- 直读 H2/OrientDB 需 JVM 或重写 MVStore/PCL 解析器，违反单二进制与零 C 依赖、且脆弱耦合 Nexus 内部 schema——代价远超其覆盖的一小撮配置。

## 后果
- 正面：默认路径匹配真实大存量场景，迁移更快更稳；纯 Rust/单二进制约束不被打破；配置手动补通道覆盖「Nexus 已彻底下线」的硬场景。
- 负面与约束：新增 Nexus 文件型 blob store 的 `.properties`/`.bytes` 解析实现；配置双来源（REST + 手动）使向导源配置步与执行器分支增多；原生数据目录一致性依赖运维停写/快照，属操作约束而非工具保证；手动补配置时 proxy 上游/group 拓扑的正确性由管理员负责，工具只做校验与显式记录。

## 备选方案
- 维持 ADR-0007 原框架（在线 + 自有包双入口，在线为默认）：数百 GB 在线不现实、强制打包多拷一遍，被用户否决。
- 直读磁盘上的 Nexus 内嵌配置库（H2/OrientDB）：纯 Rust 无成熟方案，需 JVM 或重写私有格式解析，违反技术栈约束，明确排除。
- 取消自有离线包格式：会失去可移植归档能力，用户选择保留。
- 裸 blob store 视同完整来源自动推断 proxy/group：凭路径猜配置产生错误拓扑，ADR-0007 已禁止，维持降级不变。
