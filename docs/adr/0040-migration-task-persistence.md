# ADR-0040：迁移任务与报告持久化（SQLite，取代「不落库」条款）

## 状态

已接受（取代 [ADR-0019](0019-async-migration-jobs.md) / [ADR-0038](0038-unified-task-registry.md) 中「迁移任务不落库、重启即清」的条款；两者的异步任务模型、统一注册表、迁移单飞、有界内存历史等其余决策仍有效）

## 背景

ADR-0019 / ADR-0038 确立了迁移异步任务「进程内、不落库、重启即清、靠幂等重跑恢复」的模型。该模型在小库迁移下成立，但 Nexus 迁移重做（M4）面对的是上万 blob、跑数小时至数天的大迁移，暴露三个不可接受的缺口：

- **历史与报告丢失**：迁移完成后的分仓库报告只存内存，进程重启即丢，运维无法回溯「迁了什么、跳了什么、哪些失败」。
- **中断不可见**：进程重启后在途任务凭空消失，没有「上次迁移被中断」的记录，运维无从得知需要重跑。
- **刷新恢复受限**：刷新网页找回进度依赖后端进程存活，跨重启无法恢复视图。

用户明确要求：迁移要有持久的迁移记录与报告，刷新网页可回到上一次迁移的进度里。

## 决策

迁移任务的**记录、进度快照与分仓库报告**经 `meta` 层持久化到 SQLite；**执行态不跨重启续跑**，中断恢复靠幂等重跑：

- **新增迁移任务表**（经 `meta` 层读写，其他模块不得绕过）：任务记录（id、迁移类别、状态、参数快照、起止/更新时间、错误信息）+ 进度快照 + 分仓库明细报告（源/目标仓库、格式、迁移数、跳过数、失败清单与原因、字节数、耗时）。表结构细节归 FR-140 的实现与迁移脚本，遵循 ADR-0031（迁移只增不改不删）。
- **节流落库**：运行中进度快照按节流策略定期落库（不逐 asset 写库，避免写放大）；状态变更（暂停/继续/取消/终态）即时落库；终态时写入完整报告。
- **中断标记**：进程启动时把库中残留的 `running` / `paused` 迁移任务统一归为「已中断（interrupted）」；前端可对已中断任务一键「重跑续传」——幂等重跑（目标已存在且 sha256 一致即跳过，进度区分「跳过 / 新搬」计数），等效断点续传。**不持久化枚举游标、不做自动断点续跑**。
- **运行态真源不变**：进程内 `TaskRegistry` / 迁移进度专表仍是运行中任务的实时真源（ADR-0038 模型不变）；SQLite 中的任务记录是**历史与恢复视图**，由后台任务在节流点与终态同步写入，不构成运行态第二真源。任务列表 = 内存活跃任务 ∪ 库中历史记录。
- **范围仅迁移**：在线更新（已有 `update-state.json` 终态留存）与漏洞库刷新（周期循环、无历史价值）不落库，维持既有机制。
- **凭据红线不变**：参数快照只存 `auth_ref` 引用与非敏感配置，凭据真值仍只在环境变量，绝不入库、不进日志。

## 理由

- 迁移是低频但单次代价极高的运维操作，历史记录与报告本身就是交付物的一部分；「重启即丢」对数小时级任务不可接受，此条款的收益假设（省一份真源维护）在大迁移场景下不再成立。
- 只落「记录 + 快照 + 报告」、不落「执行游标」，把复杂度压在最低：恢复语义统一为幂等重跑（引擎已具备 sha256 跳过与增量计数，FR-134），无需维护可续跑队列的一致性。
- 经 `meta` 层落 SQLite 守架构不变量：SQLite 仍是元数据唯一真源、不引外部组件；节流写库避免迁移热路径的写放大。
- 中断标记让「进程重启」从静默丢失变为显式可恢复事件，直接支撑「刷新/重启后回到上次迁移」的需求。

## 后果

- 正面：迁移历史与分仓库报告跨重启可查；在途任务重启后有「已中断」记录并可一键幂等续传；刷新网页/换浏览器均可从历史找回。
- 负面 / 约束：迁移任务状态存在内存与 DB 两处（以「内存为运行态真源、DB 为节流快照」收敛，终态强一致）；新增表与迁移脚本的维护成本；进度快照有节流延迟（重启后看到的进度可能略旧，重跑幂等消化）。
- ADR-0019 / ADR-0038 的「不落库」条款自本 ADR 起失效，其状态行同步标注。

## 备选方案

- **完整断点续跑（持久化枚举游标与队列，重启自动续）**：需把枚举游标、下载队列、单飞归属全部落库并维护一致性，复杂度高；相比幂等重跑只省一次点击与一轮枚举时间，收益不抵复杂度。落选。
- **只落终态报告，进度不落库**：实现最小，但进程重启后在途任务无「已中断」记录、进度视图无法恢复，不满足需求。落选。
- **维持纯内存（现状）**：与用户需求直接冲突。落选。
- **所有任务类型统一持久化**：更新已有终态状态文件、漏洞刷新为周期循环无历史价值，统一落库是过度设计。落选。
