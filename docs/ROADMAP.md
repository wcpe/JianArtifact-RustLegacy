## 2. 工序原则

- 每个域按 [ADR-0014](adr/0014-frontend-first-delivery.md) 的三步工序推进：**契约骨架 → 前端 + devmock → 后端业务实现**。契约骨架合入即视为契约冻结草案，改契约须同步前端与 devmock。
- 各阶段内允许**按域流水**：域 A 进入阶段 3 时，域 B 可仍在阶段 2；阶段门禁按域判定。
- 跨域公共件（工程基座、契约骨架框架接线等）不参与按域流水，必须先行完成并整体过门禁。

## 3. M2–M5 展望

- **M2 高频格式扩展**：Docker/OCI、Cargo、PyPI、Go、NuGet 等高频格式与全局跨仓库搜索。
- **M3 企业认证、存储与运维**：OIDC/LDAP、更细粒度权限、S3 兼容存储、审计与指标、备份恢复。
- **M4 安全、供应链与运营可见性**：限流与应用层防护、漏洞库镜像与扫描、使用分析。
- **M5 长尾格式与成熟期能力**：长尾格式、高级虚拟仓库策略、多节点与外部存储可选方案。
